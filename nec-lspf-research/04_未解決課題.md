## A. がん医療関連（重点調査の7テーマ）

### P1. 治療費と生活費の負担 ―「通院が長く続く人」の負担と、新しい年間上限の取りこぼし

| 問い | 回答 |
|---|---|
| 誰が | 外来の抗がん剤・分子標的薬などで、毎月の自己負担が月額上限をわずかに下回る状態が続く人とその世帯 |
| いつ | 治療開始から1年以上の通院期間。年間上限の計算期間は8月〜翌7月〔S16〕 |
| 何ができず | 年間上限を超えた分は**いったん窓口で払い、後で償還**される〔S16〕。協会けんぽでは**申請が必要で、受付は2027年8月から**〔S19〕。70歳未満は医療機関ごと・区分ごとに21,000円以上の負担しか合算できず、年間上限の申請でも同じ〔S19〕。自分がいくら戻るのかを追えない |
| 深刻さ | 例：区分ウで毎月6.5万円が12か月続くと78万円。年間上限53万円との差25万円が戻る〔S26 解説の試算〕 |
| 頻度 | 医療の金銭的負担が原因で生活に影響があった人は24.2%、若年患者は44.9%〔S14〕 |
| 現在の対処 | 高額療養費の利用74%、限度額適用認定証56%〔S23〕。マイナ保険証なら月額上限は窓口で自動適用〔S16〕 |
| 既存手段の不足 | 月額上限は自動化が進んだが、**年間上限は償還払い・申請制**で、患者が自分で集計・申請する必要がある。保険者が変わった場合、既存の「外来年間合算」では、他の保険者すべてから自己負担額証明書を取り寄せる必要がある〔S21〕。八尾市は、基準日前1年以内に他の保険に加入していた人には通知が届かない場合があると案内している〔S20〕 |
| 統計 | 上記〔S14, S16, S19, S23〕 |
| 費用負担者 | 患者本人（現状）。解決の受益者は患者と、申請対応を担う保険者（市区町村国保、健保組合）【推論】 |
| NECの参入理由 | 市区町村は国保の保険者でもある。NECは自治体の基幹系・住民ポータルを提供しており、国保側の案内・申請受付と住民側のナビをつなげられる【推論】 |
| データ蓄積 | 月ごとの自己負担額、所得区分、加入保険の変遷、償還額。本人同意のもとでマイナポータルの医療費情報を取得できる〔S32〕 |
| WoLN非重複 | ○（医療費の金額を資金計画に使う。健康予測には使わない） |
| 未確認 | **新しい年間上限で、計算期間中に保険者が変わった場合に通算されるか、どの書類が必要か**（一次資料で未確認） |

### P2. 治療に伴う収入減少 ― 傷病手当金の未利用と「辞める順番」のミス

| 問い | 回答 |
|---|---|
| 誰が | 診断時に働いている人（がん患者の44.1%、若年患者は78.6%）〔S14〕 |
| いつ | 診断直後〜治療開始前（退職者の58.3%は治療開始前に退職〔S14〕）、休職開始時、退職を考えたとき |
| 何ができず | 休職で収入が減るが、使える給付を使えていない。**連続4日以上休職した人は71%なのに、傷病手当金の利用は36%**〔S23〕（国保加入者・有給休暇で対応した人など対象外の人も含むため、差の全部が取りこぼしではない）。退職日に出勤すると傷病手当金の継続給付を受けられない〔S22〕など、手続きの順番を誤ると取り戻せない |
| 深刻さ | 収入は平均20%減。生活が苦しいと感じた人75%、そのうち46%は治療開始から半年以内〔S23〕 |
| 頻度 | 収入が減った人53%、休職が理由の人50%〔S23〕。年間約90万人が新たにがんと診断され、約3割が就労世代〔S27〕 |
| 現在の対処 | 貯蓄の取り崩し62%、生活費の節約52%、公的制度44%、民間保険36%〔S23〕 |
| 既存手段の不足 | 治療開始前に医療スタッフから就労継続の話があった人は44.0%〔S14〕。退職の判断は職場で起き、病院の相談支援センターに届く前に決まってしまう【推論】 |
| 費用負担者 | 患者本人。企業（人材の流出）、健保・国保（給付の適正運用）も影響を受ける【推論】 |
| NECの参入理由 | 企業向けにも自治体向けにも接点がある。中立な立場で、雇用主・保険者・本人をつなげる【推論】 |
| データ蓄積 | 雇用形態、勤続年数、休職開始日、有給残、給付の申請・受給履歴、収入の推移 |
| WoLN非重複 | ○ |

### P3. 就労継続と職場の調整

| 問い | 回答 |
|---|---|
| 誰が | 治療を続けながら働く人と、その職場（特に人事部門がない中小企業） |
| いつ | 通院日程・副作用で勤務を変える必要が出たとき、復職時 |
| 何ができず | どの配慮を、どの書類で、誰に頼めばよいか分からない |
| 深刻さ・頻度 | 勤務上の配慮があったと思う人74.5%、社内制度を利用した人70.6%〔S14〕。逆に約4分の1は配慮を感じていない。離職した人の理由の65%が「治療と仕事の両立が難しかった」〔S23〕 |

| データ蓄積 | 勤務配慮の内容、休職・復職日、職種別の両立パターン |
| WoLN非重複 | ○ |

### P4. 公的支援制度の利用障壁（障害年金を例に）

| 問い | 回答 |
|---|---|
| 誰が | 治療の影響で働き方が大きく制限された人 |
| いつ | 初診日から1年6か月後（障害認定日）など、時間が経ってから |
| 何ができず | がん患者も障害年金の対象になりうることを知らなかった人34.2%、請求した人18.0%〔S24〕。請求しなかった理由は「受け取れるかもしれないと考えたことがなかった」45.7%、「知らなかった」25.4%、「相談先が分からない」19.1%〔S24〕 |

| WoLN非重複 | ○ |

## C. 優先すべき課題の結論

**P1・P2・P4・P7は一つの課題の別の面である。** 「病気で働けなくなる人の収入ショックに対し、制度（保険者・年金・税・自治体）、民間（保険・金融）、職場の手続きがバラバラで、順番と期限を誤ると取り戻せない」。

- 実在性：NCC、ライフネット生命、キャンサーネットジャパンの調査がそろって示している〔S14, S23, S24〕
- 緊急性：2026年に制度が2つ変わった（高額療養費の年間上限〔S16〕、両立支援の努力義務〔S28〕）
- 未充足：相談支援センターは役立つが届いていない（知っている人の21.1%しか使っていない）〔S14〕。制度検索サイトは「可能性のある制度の一覧」まで〔S25〕
- 既存制度で解決済みの部分：月額の高額療養費（マイナ保険証で窓口自動適用）〔S16〕、医療費控除（マイナポータルの医療費通知情報をe-Taxに取り込む仕組みが一般に知られている。本調査では出典を未確認）は、新サービスの価値の中心にしない
